Orion Media investigated a sharp increase in cloud infrastructure cost after launching a new video-rendering workflow. Most of the increase came from orphaned GPU instances and cross-region data transfer created by a new rendering workflow. Storage growth contributed modestly, while database usage stayed close to its previous baseline. Reserved-instance pricing was not the main source of the increase.

The team terminated idle GPU instances, moved the rendering workload to a single region, and tightened autoscaling limits. Daily cloud spend fell the following week without a measurable increase in render time. Engineers also added a nightly report that flags GPU resources with no active jobs so that unused capacity can be reviewed before it remains online for several days.
